# 5. 솔라피(문자 대행발송) 가입

비서가 학부모께 문자를 **보내는** 길입니다. 받는 길(4단계)과 별개입니다.

## 5-1. 가입·발신번호 인증

1. https://solapi.com 가입 → 콘솔.
2. **발신번호 등록**: 학원 대표번호 또는 원장 폰 번호를 등록하고 인증(ARS/서류). 인증 안 된 번호로는 발송이 거부됩니다.
3. **API 키 발급**: 콘솔 → API Key 관리 → 새 키. `API Key` 와 `API Secret` 두 개를 받습니다.
4. 충전: 문자 1통 약 20원 안팎(2026년 기준, LMS 는 더 비쌈). 처음엔 1만 원이면 몇 달 갑니다.

## 5-2. .env 에 넣기

```
SOLAPI_API_KEY=...
SOLAPI_API_SECRET=...
SOLAPI_FROM=01012345678    # 인증한 발신번호, 숫자만
```

## 5-3. 테스트 (내 번호로)

```bash
cd /root/wonjang-ai-secretary && set -a && source .env && set +a
python3 scripts/send_sms.py 010-내-번호 - <<< "비서 발송 테스트입니다."
```

`{"successCount": 1, ...}` 이 찍히고 폰에 문자가 오면 끝. `data/sent-sms.jsonl` 에 원문이 남습니다.

## 5-4. 비서가 문자를 보내는 흐름

이 레포의 `CLAUDE.md` 에 박혀 있는 규칙입니다. 바꾸지 않는 걸 권합니다.

1. 학부모 문자가 오면 비서가 **답장 초안**을 텔레그램으로 보여줍니다.
2. 원장이 **"ㄱ"** 한 글자를 보내면 비서가 `send_sms.py` 로 발송하고, 성공(`successCount>0`)을 확인한 뒤 "발송했어요"라고 보고합니다.
3. 원장이 문안을 고치면(예: "학원 이름 빼") 비서가 고친 초안을 다시 보여주고 다시 ㄱ 을 기다립니다.

승인 없이 나가는 문자는 없습니다. 이게 이 구성에서 제일 중요한 안전장치입니다.

---

여기까지 하면 끝입니다. 이제 원장은 텔레그램만 봅니다.
문자가 오면 비서가 정리해 주고, 초안에 ㄱ 만 치면 답장이 나가고, 밤 11시엔 그날 업무일지가 옵니다.

몇 주 쓰다 보면 "앞으로 이런 건 이렇게 해"가 쌓입니다. 그걸 비서가 `memory/` 에 저장하고 다음 날도 지킵니다.
그때부터가 진짜 비서입니다.
